# MVP User Stories

## User registration and authentication
- As a new user, I want to be able to create an account by providing a username, email, and password, so that I can access the features of the webapp.
- As a registered user, I want to be able to log in using my email and password, so that I can access my account and use the webapp.
- As a logged-in user, I want to be able to log out of my account, so that I can ensure the security of my account when I'm done using the webapp.
- As a user, I want to be able to reset my password if I forget it, so that I can regain access to my account.

## User profiles and friend management
- As a user, I want to be able to view and edit my profile information, such as my bio and profile picture, so that I can personalize my account.
- As a user, I want to be able to see a list of my friends and their profiles, so that I can connect with them and view their recipes.
- As a user, I want to be able to search for other users by username or email, so that I can find and connect with friends on the webapp.
- As a user, I want to be able to send friend requests to other users, so that I can connect with them and view their recipes.
- As a user, I want to be able to accept or reject friend requests from other users, so that I can manage my connections on the webapp.
- As a user, I want to be able to see a list of my pending friend requests, so that I can keep track of who I have sent requests to and who has sent requests to me.
- As a user, I want to be able to remove friends from my friend list, so that I can manage my connections on the webapp.
- As a user, I want to be able to create and manage friend groups, so that I can organize my friends and share recipes with specific groups of people.
- As a user, I want to be able to view the profiles of my friends and friend groups, so that I can see their recipes and share recipes with them.

## Recipe creation and management
- As a user, I want to be able to create new recipes by providing a title, description, ingredients, and instructions, so that I can share my recipes with others.
- As a user, I want to be able to edit my existing recipes, so that I can update them with new information or improvements.
- As a user, I want to be able to delete my recipes, so that I can remove recipes that I no longer want to share.
- As a user, I want to be able to view a list of my recipes, so that I can easily access and manage them.
- As a user, I want to be able to view the details of a recipe, including the title, description, ingredients, instructions, and author information, so that I can see all the relevant information about the recipe.
- As a user, I want to be able to mark my recipes as public or private, so that I can control who can see them on the webapp.
- As a user, I want to be able to see which of my friends have made a recipe, so that I can connect with them and see their photos and comments on the recipe.
- As a user, I want to be able to upload photos of my recipe when I make it, so that I can share my cooking results with others.

## Recipe search and discovery
- As a user, I want to be able to search for recipes by title, ingredients, or author, so that I can find recipes that I'm interested in.
- As a user, I want to be able to filter search results by criteria such as dietary restrictions, cooking time, or popularity, so that I can find recipes that meet my specific needs.

# MVP User Stories

## User registration and authentication
- As a new user, I want to be able to create an account by providing a username, email, and password, and receive a confirmation email to verify my account.
- As a registered user, I want to be able to log in and stay logged in across sessions (Refresh Tokens).
- As a user, I want to be able to reset my password via an email link if I forget it.

## User profiles and friend management
- As a user, I want to be able to use the app in my preferred language (English or Norwegian).
- As a user, I want to be able to toggle notifications for social events in my settings.
- As a user, I want a Dashboard feed that combines friend activity and recipes shared in my groups.
- As a user, I want to send/receive friend requests and manage my friend list.
- As a user, I want to create friend groups and **invite** friends to them.

## Recipe creation and management
- As a user, I want to create recipes using structured ingredients and standardized units.
- As a user, I want to be able to scale a recipe (e.g., 2x) automatically when viewing it.
- As a user, I want to be able to tag my recipes using a mix of predefined system tags and custom tags.
- As a user, I want to be able to soft-delete my recipes.

## Recipe search and discovery
- As a user, I want high-performance, relevance-based search.
- As a user, I want to filter by dietary tags, cook time, or popularity.

## Cookbook creation and management
- As a user, I want to create cookbooks and invite other users to be collaborators.
- As a user, I want to manage recipes in my cookbooks with enforced privacy logic.
- As a user, I want to see who has made my recipes.
